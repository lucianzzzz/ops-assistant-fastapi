一、问题描述
==============================================

用户报告：
- 访问 http://127.0.0.1:8012/api/v1/assistant/ask
- POST 请求 {"question": "cpu可以用来煮饭吗", "top_k": 3}
- 返回 500 Internal Server Error

错误信息：
```
AttributeError: 'NoneType' object has no attribute 'get'
File "app/core/service.py", line 157, in ask_with_ai
    if result.get("ai_fallback", {}).get("enabled"):
```

==============================================
二、问题排查过程
==============================================

### 1. 初步假设（错误）
最初认为 result 本身是 None，说明 ask() 方法返回了 None。

### 2. 添加异常处理（无效）
在 ask_with_ai() 中添加了 try-except 捕获异常，并在 if not result 时返回默认值。
结果：错误依然发生，说明 result 不是 None。

### 3. 缓存问题排查
多次重启后端，错误行号始终指向旧代码位置。
尝试措施：
- 删除所有 __pycache__ 目录
- 删除所有 .pyc 文件
- 使用 PYTHONDONTWRITEBYTECODE=1 禁用字节码
- 强制 kill -9 进程

### 4. 添加 Debug 日志（关键发现）
在代码中添加 print 语句追踪：
```python
print(f"[DEBUG] ask() returning result type: {type(result)}, is None: {result is None}")
print(f"[DEBUG] ask_with_ai() received result type: {type(result)}, is None: {result is None}")
print(f"[DEBUG] Before AI fallback check, result value: {result}")
```

Debug 输出显示：
```
[DEBUG] ask() returning result type: <class 'dict'>, is None: False
[DEBUG] ask_with_ai() received result type: <class 'dict'>, is None: False
[DEBUG] Before AI fallback check, result value: {
    'question': 'cpu可以用来煮饭吗',
    'confidence': 0.5,
    'ai_fallback': None,    ← 关键！
    ...
}
```

### 5. 根本原因定位 ✅

**result 不是 None，但 result['ai_fallback'] 是 None！**

问题代码：
```python
if result.get("ai_fallback", {}).get("enabled"):
```

分析：
1. 当 ai_fallback 是 None 时，result.get("ai_fallback", {}) 返回 None（而不是默认的 {}）
2. 对 None 调用 .get("enabled") 就抛出 AttributeError

为什么 ai_fallback 是 None？
- 置信度正好是 0.5
- AI 触发条件是 confidence < 0.5（严格小于）
- 所以 ai_fallback 没有被设置，保持为 None

==============================================
三、解决方案
==============================================

### 修复代码
```python
# 错误的写法
if result.get("ai_fallback", {}).get("enabled"):

# 正确的写法
ai_fallback = result.get("ai_fallback") or {}
if ai_fallback.get("enabled"):
```

### 关键点
使用 `or {}` 确保当 ai_fallback 是 None 时，返回空字典而不是 None。

==============================================
五、技术总结
==============================================

### 1. Python dict.get() 的陷阱

```python
# 当值是 None 时，默认值不会生效
result = {"key": None}
result.get("key", {})  # 返回 None，不是 {}！

# 正确的写法
result.get("key") or {}  # 返回 {}
```

### 2. AI 触发条件
```python
confidence < 0.5  # 严格小于 50%
```

边界情况：
- confidence = 0.49 → 触发 AI
- confidence = 0.50 → 不触发 AI（ai_fallback = None）
- confidence = 0.51 → 不触发 AI

### 3. 缓存问题排查
Python 缓存机制：
- __pycache__/ 目录
- .pyc 字节码文件
- 运行时模块缓存

强制重新加载：
```bash
# 删除缓存
find . -type d -name __pycache__ -exec rm -rf {} +
find . -name "*.pyc" -delete

# 禁用字节码
PYTHONDONTWRITEBYTECODE=1 uvicorn ...
```

六、经验教训
==============================================

1. **dict.get() 的默认值在值为 None 时不生效**
   - 需要使用 `or {}` 来处理 None 值

2. **边界条件很重要**
   - 置信度 0.5 正好在临界点
   - 需要测试 <、=、> 三种情况

3. **Debug 日志比猜测有效**
   - 直接打印变量值能快速定位问题
   - 不要过早假设问题原因

4. **Python 缓存可能导致代码未更新**
   - 修改后记得清除缓存
   - 使用 PYTHONDONTWRITEBYTECODE=1

```python
async def ask_with_ai(self, question: str, province: str = "", top_k: int = 3) -> dict[str, Any]:
    result = self.ask(question, province, top_k)

    # ❌ 错误：当 ai_fallback 是 None 时会报错

```

### 修复后（正确）
```python
async def ask_with_ai(self, question: str, province: str = "", top_k: int = 3) -> dict[str, Any]:
    try:
        result = self.ask(question, province, top_k)
    except Exception as e:
        print(f"Error in ask(): {e}")
        # 返回默认结果
        return {...}

    if not result:
        # 防御性检查
        return {...}

    # ✅ 正确：使用 or {} 处理 None 值
    ai_fallback = result.get("ai_fallback") or {}
    if ai_fallback.get("enabled"):
        ai_result = await self.ai_assistant.ask(question)
        ...
```
